# ⚽ 11×11 — премиальный футбольный портал (PHP · MySQL · XAMPP)

Полноценный веб-портал о футболе с иерархией ролей, модерацией контента,
трансферным рынком и мгновенным поиском. Тёмно-изумрудный «стадионный»
дизайн со стеклморфизмом и неоново-зелёными акцентами (Tailwind CSS).

## 🚀 Установка на XAMPP

1. Установите и запустите **XAMPP** → включите модули **Apache** и **MySQL**.
2. Скопируйте папку проекта в `C:\xampp\htdocs\11x11`.
3. Откройте в браузере: **http://localhost/11x11/**
   * База данных `db11x11`, таблицы и учётная запись владельца создаются
     **автоматически** при первом обращении (см. `config/db.php`).
4. Пароль владельца сгенерируется и один раз запишется в
   **`config/OWNER_PASSWORD.txt`**. Войдите под ним и удалите файл.

> Если хотите развернуть схему вручную — импортируйте `sql/schema.sql`
> через **phpMyAdmin** (http://localhost/phpmyadmin).

### 📰 Демо-новости (необязательно)
Чтобы наполнить портал 28 футбольными новостями (двуязычными, с фото),
импортируйте `sql/demo_posts.sql` после первого запуска:
```
mysql -uroot db11x11 < sql/demo_posts.sql
```

### 🌍 Двуязычность и категории
- Сайт работает на **английском (по умолчанию)** и **русском** — переключатель RU/EN в шапке.
- Посты создаются сразу на двух языках; посетитель видит версию по своему языку.
- **Категории** двуязычные, с иконками, хранятся в БД. Владелец добавляет/редактирует
  их в разделе **«Категории»**; при создании поста категория **подбирается автоматически**
  по ключевым словам заголовка.
- Логотип: положите свой файл в `assets/logo.png` — шапка подхватит его автоматически
  (иначе показывается векторный `assets/logo.svg`).

## 🛡 Роли и права

| Роль | Возможности |
|------|-------------|
| **owner** (Владелец) | Полный контроль: управление правами и учётками, создание/удаление админов, модерация и принудительная публикация любого поста |
| **admin** (Администратор) | Модерация постов (одобрить/отклонить), управление контентом и трансферами |
| **author** (Автор) | Создание постов, черновики (`draft`), отправка на проверку (`pending`) |

## 🔄 Жизненный цикл поста

```
draft  ──«Отправить на проверку»──►  pending  ──«Одобрить»──►  published
  ▲                                     │
  └────────────«Отклонить» (rejected)◄──┘  (с причиной, автор дорабатывает)
```

## 🔐 Безопасность

- **PDO + prepared statements** — защита от SQL-инъекций во всех запросах.
- **password_hash / password_verify** (bcrypt) — пароли не хранятся в открытом виде.
- **Сессии** + `session_regenerate_id()` при входе — защита от фиксации сессии.
- **CSRF-токены** на всех POST-формах (`csrf_field()` / `csrf_check()`).
- **checkAccess()** — middleware проверки ролей на каждой защищённой странице.
- **htmlspecialchars** (`e()`) — экранирование любого вывода (XSS).
